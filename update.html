How to Install the Update

APK file yatsitsidwa. Tsatirani njira izi kuti muipange install:

  1. Tsegulani Files app pa phone yanu
  2. Pitani ku Downloads folder
  3. Dinani pa 1akimark.apk
  4. Ngati Android ipempha, dinani Allow kuti muyitseke
  5. Dinani Install

Kapena: Tsitsani notification bar pamwamba pa phone, mukapeza "1akimark.apk downloaded. Tap to install."
